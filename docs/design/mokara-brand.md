# Mokara Interlock mark

Approved direction: two opposing, rounded geometric hooks. Keep the two pieces and the open channel between them intact.

| Asset                                                 | Intended use                                                          |
| ----------------------------------------------------- | --------------------------------------------------------------------- |
| `packages/frontend/public/mokara-mark.svg`            | Indigo mark on light surfaces; public header and footer.              |
| `packages/frontend/public/icons/mokara-icon.svg`      | White mark on an indigo tile; browser and device icons.               |
| `packages/frontend/public/brand/mokara-mark-dark.svg` | Indigo mark on a dark tile; saved for future dark-surface placements. |

Brand indigo is `#6366f1`, dark ink is `#0f172a`, and reversed artwork is `#ffffff`. The saved dark tile is not currently placed in the interface.

The favicon contains 16, 32 and 48 pixel drawings of the browser-icon asset. PNG fallbacks are 32 pixels and 180 pixels (Apple touch icon). Regenerate these from `icons/mokara-icon.svg` when changing the symbol. Public navigation uses the unboxed mark; do not substitute the browser tile there.
